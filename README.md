# Ojasvi Bhardwaj - Developer Portfolio

![Portfolio Preview](/public/contact.jpg)

A highly interactive, 3D developer portfolio built to showcase my background in software engineering, backend development, and Generative AI. The application focuses on delivering a premium, sci-fi aesthetic through modern web technologies, fluid simulations, and immersive animations.

## ✨ Key Features
- **Immersive 3D Navigation**: Features an interactive infinite scrolling menu built with Spline and Three.js.
- **Fluid WebGL Simulations**: Integrates real-time, interactive fluid dynamics (`SplashCursor`) and light pillars (`LightPillar`) for a highly engaging user experience.
- **Dynamic Content**: Career timelines, certifications, and featured projects are dynamically rendered from a centralized configuration file.
- **Modern Tech Stack**: Built from the ground up for speed, SEO, and responsiveness using the latest React and Next.js features.

## 🛠️ Technology Stack
- **Framework**: Next.js (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS v4, Vanilla CSS
- **Animations**: Framer Motion, Spline, Three.js
- **Language**: TypeScript / JavaScript

## 📁 Project Structure
- `/src/app` - Next.js routing (Home, Career, About pages).
- `/src/components` - Reusable UI components (BorderGlow, SplashCursor, LightPillar).
- `/src/data` - Centralized portfolio content (`config.ts`).
- `/public` - Static assets and images.

## ⚙️ Local Development

1. Clone the repository:
```bash
git clone https://github.com/madhav7802/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
